     *************************************************  
     *   Stock Information Management System         *
     *           About the Project                   *
     ************************************************* 

This is a Python console application that helps users manage products and stock information.
***Features***
View, add, update, delete, and search products.
Manage product categories and suppliers.
Record stock entries and adjustments.
Manage purchase and sales orders.
Check low-stock products.
View stock history.
Generate inventory reports.
***Technologies Used***
Python
Object-Oriented Programming (OOP)
Colorama
Git and GitHub
Installation
Clone the repository:
git clone https://github.com/LivSreysrossophany/project_python_online.git
***Install dependencies:***
pip install -r requirements.txt
Run the application:
python main.py
